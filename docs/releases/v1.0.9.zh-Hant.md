# v1.0.9

發佈日期：2026-10-14 · 建置版本：11 · **非強制更新**

[English](https://github.com/xweiba/location-spoofer/blob/v1.0.9/docs/releases/v1.0.9.en.md) · [简体中文](https://github.com/xweiba/location-spoofer/blob/v1.0.9/docs/releases/v1.0.9.md)

## 主要更新

- 針對部分安裝環境下 App 置中、上下出現大塊黑邊的問題（#15），加入標準啟動畫面，避免啟動畫面宣告遺失或未被辨識時進入舊螢幕相容模式。
- 加入啟動畫面打包檢查與迴歸測試，確保建置產物包含對應的啟動畫面資源。
- 本次為非強制更新，舊版本可繼續使用；遇到顯示問題的使用者建議升級並重新簽署安裝。

## 驗證與適用範圍

- 已在 iPhone 12 Pro Max / iOS 18.6 模擬器驗證地圖及設定頁顯示，並完成啟動畫面資源測試、非強制更新策略測試及契約測試。
- 移除啟動畫面宣告的對照包可重現 #15 的黑邊，使用標準啟動畫面後恢復正常。使用者原安裝包的簽署處理尚未核實；iOS 18.6.2 仍需實機確認。

## 自行簽署與安裝

- 下載 Release 附件中的未簽署 IPA，自行簽署後安裝。
- 簽署時請保留 Bundle ID、App Group、原有 entitlements，以及啟動畫面宣告與資源。
